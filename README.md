# Тишинский бульвар

Учебный адаптивный лендинг жилого комплекса. Вёрстка по макету и интерактивные элементы на чистом JavaScript.

## Технологии

HTML5, SCSS, CSS, JavaScript без фреймворков. Адаптивные изображения через `picture` и `srcset`, SVG-спрайт, локальные шрифты.

## Возможности

- Меню с переходами по секциям, закрытием по Escape и клику вне меню.
- Переключение трёх дворов с обновлением изображения и активной кнопки.
- Проверка имени, российского номера телефона и согласия в форме заявки. Ошибки не сдвигают элементы формы.
- Диалоговый видеоплеер с остановкой ролика при закрытии и возвратом фокуса на кнопку.
- Адаптивная вёрстка для компьютера, планшета и телефона.

Форма демонстрационная: данные не отправляются на сервер.

## Запуск

Из папки проекта выполните:

```bash
python3 -m http.server 3010 --bind 127.0.0.1
```

Откройте http://127.0.0.1:3010/. Зависимости для запуска не нужны.

## Структура

- `index.html` — разметка страницы.
- `scss/` — исходные стили; `scss/style.scss` — точка входа.
- `css/style.css` — готовые стили, подключённые на странице.
- `js/menu.js` — навигация.
- `js/courtyards.js` — переключение дворов.
- `js/request-form.js` — проверка формы.
- `js/video.js` — видеоплеер.
- `images/`, `fonts/`, `video/` — ресурсы.

При изменении SCSS нужно пересобрать `css/style.css` с помощью Sass. Браузер читает CSS, а не SCSS.

## Проверка перед публикацией

- Открытие и закрытие меню мышью и клавиатурой.
- Переключение всех дворов на широком и узком экране без скачка высоты.
- Пустая форма, неверный телефон, отсутствие согласия, успешная проверка.
- Запуск видео, закрытие по крестику и Escape, остановка звука.
- Ширины 360, 768 и 1440 px: переносы текста, отсутствие горизонтальной прокрутки.
